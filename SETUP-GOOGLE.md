# Настройка Google: инструкция для владельца

Игра уже подготовлена под твой репозиторий. Для автоматического сбора нужно один раз создать таблицу и веб-приложение в твоём Google-аккаунте.

## 1. Создай таблицу

Создай новую пустую Google Таблицу, например «Ещё один ход — результаты».

Оставь доступ **Ограниченный**. Участникам не нужна ссылка на таблицу.

## 2. Добавь обработчик

1. В таблице открой **Расширения → Apps Script**.
2. В редакторе открой Code.gs и замени его содержимое кодом из [apps-script/Code.gs](apps-script/Code.gs) этого репозитория.
3. Сохрани проект. Название, например: «Ещё один ход — сбор результатов».
4. В списке функций сверху выбери **setup** и нажми **Выполнить**.
5. Google запросит разрешение твоему скрипту работать с таблицами. Проверь, что это именно созданный тобой проект, и выдай разрешение, если согласен.
6. Вернись в таблицу. Должны появиться листы **Sessions**, **Mines**, **Events** с заголовками.

setup сохраняет ID текущей таблицы в свойствах проекта. Его не требуется вставлять в игру. Повторный запуск setup не стирает данные. Стандартный пустой лист можно оставить.

Файл appsscript.json приведён для справки; вручную заменять его для обычного запуска не требуется. Скрипт использует среду V8.

## 3. Опубликуй веб-приложение

1. В Apps Script нажми **Развернуть → Новое развертывание**.
2. Выбери тип **Веб-приложение**.
3. **Выполнять от имени:** ты / «Я».
4. **У кого есть доступ:** **Все / Anyone**, включая пользователей без входа в Google.
5. Нажми **Развернуть** и скопируй URL веб-приложения, который заканчивается на **/exec**.

Доступ к веб-приложению и доступ к самой таблице — разные настройки. Публичный обработчик умеет только принимать записи, сообщать готовность и подтверждать получение конкретного пакета. Он не выдаёт содержимое таблицы. Не публикуй саму таблицу.

Если в университетском аккаунте нет доступа «Все», администратор мог ограничить такие развертывания. Для этой схемы нужен аккаунт, в котором разрешено анонимное выполнение веб-приложений. Вариант «Только я» не подходит.

## 4. Соедини игру с обработчиком

В файле config.js замени пустое значение endpoint:

```js
endpoint: 'https://script.google.com/macros/s/ТВОЙ_ID/exec',
```

Вставь адрес целиком, сохранив кавычки. Это должен быть URL развертывания **/exec**, а не ссылка редактора, таблицы или тестового развертывания **/dev**.

Можно прислать этот адрес в чат, чтобы внести его в репозиторий. Он будет виден в коде публичной игры; не вставляй вместо него пароль или API-ключ.

После коммита дождись обновления GitHub Pages. Стартовая страница проверит готовность обработчика и разрешит начать игру.

## 5. Проверь на отдельной тестовой сессии

1. Открой публичную игру в новом приватном окне.
2. Начни, сделай несколько ударов, купи улучшение, перейди на новый участок.
3. Нажми «Закончить экспедицию».
4. Дождись «Результат сохранён. Спасибо!».
5. Проверь в своей таблице одну сессию в Sessions, шахты в Mines и действия в Events. session_id должен совпадать.
6. Обнови итоговую страницу: строки событий не должны дублироваться.
7. Открой игру без интернета уже после старта, сделай несколько действий и восстанови связь: отправка должна повториться.

Не включай эти тестовые сессии в результаты исследования. Отметь их session_id у себя. В репозитории нет придуманных ответов или заранее заполненной статистики.

## Если не работает

- **«Экспедиция ещё готовится»**: проверь endpoint, запуск setup и наличие трёх листов.
- **«Не удалось подключиться»**: проверь адрес /exec, анонимный доступ и доступность Google в сети игрока.
- **Результат остаётся на устройстве**: посмотри раздел «Выполнения» в Apps Script. При отказе записи браузер не выдаёт успех и сохраняет пакет для повтора.
- **Скрипт обновлён, но поведение старое**: в Apps Script открой «Управление развертываниями», измени существующее развертывание и выбери новую версию.
- **Сессия осталась playing**: игрок мог закрыть вкладку, потерять связь или не нажать завершение. Не считай это добровольным выходом по кнопке.
- **Google достиг лимита сервиса**: приём зависит от квот Apps Script. Для домашней работы с небольшой выборкой схема подходит; перед большим набором проведи нагрузочную проверку.
